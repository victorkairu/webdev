WebDev – Member Registration

Course: SPI 2201 – Web Application Development I
Institution: Kirinyaga University
Academic Year: 2026/2027

Project Description

WebDev – Member Registration is a small, beginner-friendly web application designed to demonstrate HTML, CSS, JavaScript, JavaScript events, and DOM manipulation through a member registration form.

Features

- Member registration form
- Input validation
- Email format validation
- Password confirmation
- Duplicate email checking
- Dynamic display of registered members
- Automatic member count updates
- Dark mode toggle
- Responsive and user-friendly interface

Technologies Used

- HTML5 – structures the webpage
- CSS3 – styles the interface
- JavaScript – implements application logic
- JavaScript Events – responds to user interactions
- DOM Manipulation – updates webpage content dynamically

How to Run

1. Clone or download this repository.
2. Open "index.html" in a web browser.
3. Complete the registration form and test its features.

Limitations

This demonstration stores registered members temporarily in browser memory. The data is cleared when the page is refreshed. It does not use a backend server or database.

Learning Outcomes

The project demonstrates the practical use of form handling, input validation, event listeners, DOM manipulation, and CSS styling in a simple web application.
